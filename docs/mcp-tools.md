# MCP Tools Reference

> **Status**: Coming soon. This document will contain the full catalog of MCP tools exposed by Agentic Browser.

## Overview

Agentic Browser exposes browser control capabilities as MCP tools via the companion MCP server. Each tool maps to a browser operation (navigation, DOM interaction, screenshots, etc.).

## Tool Categories

- **Navigation** — URL navigation, history, page lifecycle
- **DOM Interaction** — Click, type, select, hover, scroll
- **Tab Management** — Create, close, list, switch tabs
- **Content Extraction** — HTML, accessibility tree, structured data
- **Screenshots** — Full page and element captures
- **Script Execution** — JavaScript execution in page context
- **Dialog Handling** — Alert, confirm, prompt management
